# Agentic AI Course

A hands-on project built while learning Agentic AI using LangChain and Ollama.

## Features

- LangChain
- Ollama (Qwen3)
- Tool Calling
- Multi-tool Agents
- GitHub API Integration
- Conversation Memory
- Window Memory
- Summary Memory

## Tech Stack

- Python
- LangChain
- Ollama
- Requests
